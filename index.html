03 열린 피드백

다른 관점을 배우고 피드백을 반영하며,

작은 수정도 실제 화면에서 확인하며, 함께 납득할 수 있는 방향으로 다듬어갑니다.

What I Can Do

각 항목을 선택해 사용 도구와 작업 역량을 확인할 수 있습니다.

디자인을 실제 경험할 수 있는 웹 화면으로 구현합니다.

  • HTML5

    시맨틱 태그를 활용해 웹페이지의 정보 구조와 콘텐츠 흐름을 체계적으로 구성할 수 있습니다.

  • CSS3

    Grid, Flexbox, Media Query를 활용해 디자인을 구현하고 다양한 화면에 대응하는 반응형 레이아웃을 제작할 수 있습니다.

  • JavaScript

    슬라이드, 메뉴, 스크롤 애니메이션 등 사용자와 상호작용하는 웹 인터페이스를 구현할 수 있습니다.

  • Responsive Web

    PC, Tablet, Mobile 환경에 맞춰 콘텐츠 구조와 레이아웃이 자연스럽게 변화하도록 구현할 수 있습니다.

브랜드와 사용자를 연결하는 시각적 경험을 만듭니다.

  • Illustrator

    로고, 아이콘, 벡터 그래픽과 다양한 시각 디자인 요소를 제작할 수 있습니다.

  • Photoshop

    이미지 보정과 합성, 배너·팝업·상세페이지 등 웹 그래픽을 제작할 수 있습니다.

  • Figma

    웹 UI 설계부터 컴포넌트, 프로토타입과 반응형 인터페이스 디자인까지 제작할 수 있습니다.

더 나은 결과를 위해 효율적인 협업과 개발 환경을 구축합니다.

  • Git

    작업 내용을 버전별로 관리하고 변경 사항을 체계적으로 기록할 수 있습니다.

  • GitHub

    프로젝트 소스를 관리하고 GitHub Pages를 활용한 웹사이트 배포가 가능합니다.

  • Notion

    기획 자료와 프로젝트 일정을 정리하고 작업 내용을 문서화하여 관리할 수 있습니다.

후기Q&A
★★★★★한**님

욕실을 차분한 분위기로 바꾸면서 포레스트 클렌저도 함께 골랐어요. 저녁 샤워할 때 천천히 거품을 내서 쓰는데 하루를 정리하는 느낌이 좋네요. 피부를 세게 문지르기보다는 손으로 부드럽게 씻고 충분히 헹구고 있습니다. 용기도 선반에 잘 어울리고 같은 라인의 바디 밤을 옆에 두니 샤워 후 동선이 편해졌어요.

★★★★오**님

저녁 샤워용으로 골랐는데 욕실을 차분한 분위기로 정돈하려던 목적과 잘 맞았어요. 손에 덜어 부드럽게 씻거나 평소 쓰는 도구에 소량을 묻혀 사용하고 있습니다. 처음부터 많이 덜지 않으니 원하는 사용량을 찾기 편하네요. 샤워 후에는 기존에 쓰던 바디 제품으로 마무리하는 편이고, 클렌저만 먼저 바꾸어 사용감을 살펴봤습니다. 욕실 선반에서 손이 잘 닿는 자리에 두니 준비 과정도 단순해졌고, 다른 소품과도 잘 어울려 공간을 크게 바꾸지 않아도 분위기가 달라졌어요.

★★★서**님

숲을 연상시키는 패키지 분위기가 마음에 들어 선택했습니다. 욕실에 여러 제품을 놓기보다 이 클렌저를 꺼내두고 자주 사용하고 있어요.

★★★★신**님

포레스트 캄 바디 클렌저을 가까운 곳에 꺼내 두고 쓰고 있어요. 저녁 샤워 때 조금씩 덜어 거품을 내어 사용하고 있어요. 욕실에서 꺼내 쓰기 편한 자리에 두니 매일의 루틴에 잘 들어왔습니다.
사용하는 공간에서 찍어 보니 패키지도 잘 어울려서 사진을 함께 올립니다.

★★★★★권**님

포레스트 캄 바디 클렌저을 골라 사용하면서 저만의 루틴을 만들어 보고 있어요. 처음에는 소량으로 시작했고 필요한 순간 꺼내 쓰고 있습니다. 구성과 사용 안내를 확인하기도 편해서 잘 사용하고 있어요.
